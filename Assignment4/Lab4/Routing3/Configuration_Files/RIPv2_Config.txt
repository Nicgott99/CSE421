================================================================================
Routing Task 3: Configuring RIPv2 (Routing Information Protocol Version 2)
Dynamic Routing Configuration
================================================================================

Task Overview:
Configure RIPv2 dynamic routing protocol on three routers (R1, R2, R3)
to enable automatic route discovery and path selection across the network.

================================================================================
ROUTER R1 CONFIGURATION COMMANDS
================================================================================

Enable Privileged Mode:
R1>enable

Enter Configuration Mode:
R1#configure terminal

Configure Default Route:
R1(config)#ip route 0.0.0.0 0.0.0.0 s0/0/1

Enable RIP Router:
R1(config)#router rip

Set RIPv2:
R1(config-router)#version 2

Add Networks to RIP:
R1(config-router)#network 192.168.1.0
R1(config-router)#network 192.168.2.0

Disable Auto-Summary:
R1(config-router)#no auto-summary

Originate Default Information:
R1(config-router)#default-information originate

Set Passive Interface:
R1(config-router)#passive-interface g0/0
R1(config-router)#exit

Exit Configuration:
R1(config)#exit
R1#

Save Configuration:
R1#copy run start

================================================================================
RIPv2 CONFIGURATION SUMMARY
================================================================================

RIPv2 Features Implemented:
1. Version 2: Better security and VLSM support than RIPv1
2. Classless Routing: Supports variable-length subnet masks
3. Auto-Summary Disabled: Allows more precise route advertisement
4. Default Route Propagation: Originate default-information for ISP routes
5. Passive Interfaces: Prevent unnecessary routing updates on LANs

Network Participation:
- R1: Participates in networks 192.168.1.0, 192.168.2.0
- R2: Participates in networks 192.168.2.0, 192.168.3.0, 192.168.4.0
- R3: Participates in networks 192.168.1.0, 192.168.4.0, 192.168.5.0

Router Connectivity:
- R1 ↔ R2: Connected via 192.168.2.0/24
- R2 ↔ R3: Connected via 192.168.4.0/24
- R1 ↔ R3: Connected via 192.168.1.0/24 (multi-hop route)
